FORMÉ HAUS Website - How to Run

Welcome to the FORMÉ HAUS website. This is a fully functional fashion e-commerce website with Medusa v2 backend integration.

Status: The website is 95% complete and ready to use! All features work except payment processing, which requires Stripe setup (see below).

Running the Complete E-commerce Website

Important: This is NOT just a static website. It's a full-stack e-commerce application that requires both frontend and backend servers to run properly.

Quick Start (2 Simple Steps)

Step 1: Start the Medusa Backend

Option A: Double-click start-medusa-real.bat
Option B: Open terminal and run:
cd medusa-storefront
npm run dev
Backend will run on: http://localhost:9000
Check it's working: http://localhost:9000/store/products (should show JSON)

Step 2: Start the Frontend

Option A: Double-click start-frontend-real.bat
Option B: Open terminal and run:
npm run dev
Frontend will run on: http://localhost:5173
Visit this URL in your browser to see the website!

Troubleshooting

Backend Not Starting?

  • Check Docker is running: docker ps
  • Start PostgreSQL: docker start medusa-postgres
  • Check database: docker logs medusa-postgres

Frontend Shows No Products?

  • Ensure backend is running on port 9000
  • Check: http://localhost:9000/store/products
  • If empty, run seed: cd medusa-storefront && npm run seed

CORS Errors?

  • Check medusa-storefront/.env has STORE_CORS=http://localhost:5173
  • Restart backend after changing .env
