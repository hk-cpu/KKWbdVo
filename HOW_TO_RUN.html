Method 2: Using a Local Development Server (Recommended)

To get the full functionality and enable hot reloading, you can run a local development server.

Option A: Using Node.js (Recommended)

Step 1: Install Node.js from https://nodejs.org/
Step 2: After installation, double-click on start-dev-server.bat or run in terminal: 
node server.js
Step 3: Open your browser and go to http://localhost:3000

Option B: Using npm (If Node.js is installed)

Step 1: Install dependencies: 
npm install
Step 2: Start the development server: 
npm run dev
Step 3: Open your browser and go to the URL shown in the terminal (typically http://localhost:5173)
Important: It appears that Node.js is not currently installed on your system. Please install it from https://nodejs.org/ to use the development server options.
